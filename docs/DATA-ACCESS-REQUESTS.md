# Prepared data-access requests

Drafts only; no messages have been sent. The proposed service is a free, noncommercial public Canadian energy atlas, with attribution, retrieval dates and original source links.

## Québec — SIGPEG / MEIE

Request written permission to redistribute the current SIGPEG well inventory as downloadable normalized JSON/CSV and interactive public maps. Include coordinates, well identity, documented status, recorded events and source attribution. Ask whether daily automated retrieval, immutable historical snapshots, public hosting on GitHub Pages or an equivalent CDN, and derivative status normalization are permitted. Request the authoritative update endpoint, revision dates and distinctions between stratigraphic boreholes, wells without a responsible owner and other inactive wells.

Evidence: https://sigpeg.mrn.gouv.qc.ca/gpg/hydrocarbures/Licence_utilisation.pdf

## Newfoundland and Labrador — provincial energy authority

Request permission to redistribute digital onshore well records and normalized derivatives in a noncommercial public atlas. Ask for a complete current inventory, update mechanism, stable identifiers, status definitions and historical closure events. Obtain separately scoped offshore coverage and permissions from the offshore regulator; provincial onshore permission does not establish offshore rights.

Evidence: https://www.gov.nl.ca/em/energy/petroleum/onshore/onshore-maps/

## Remaining provincial inventory gaps

Nova Scotia: confirm redistribution and transformation rights for the current onshore inventory; obtain separate offshore coverage. New Brunswick: request the complete historical petroleum-well export, status definitions, current update feed and dataset licence. Prince Edward Island: request a current machine-readable inventory, identification of re-entries versus unique physical sites, onshore/offshore scope and public distribution rights. For each, request documented orphan designation and reclamation status separately from wellbore abandonment.

## Infrastructure and transport

Request a current, redistributable national pipeline/refinery/LNG dataset with stable IDs, geometry, capacity definitions and updates. The CER interactive-map geometry is excluded because its published terms prohibit redistribution. Obtain carrier-specific public schedules, commodities, routes, units, effective/end dates, surcharges and tax treatment. Contract freight prices require the carrier or shipper's permission; published tariffs cannot establish every customer's price. Never characterize a transport fee as a provincial government tariff.

## Evidence needed before enabling publication

Save the actual written authorization or open licence URL, permitted uses and attribution in the source registry. Validate complete acquisition, source dates and the adapter against authoritative counts. Run the same automated release checks and independent review before changing coverage from partial or unavailable to complete.
