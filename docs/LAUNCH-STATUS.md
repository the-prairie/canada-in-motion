# Launch status

The repository is private. Public launch is disabled. This candidate has a publication gate that requires verified national coverage, distribution rights and current evidence for each topic. Do not remove that gate to label partial data complete.

The ten provinces and three territories have source research records. Alberta, British Columbia, Saskatchewan, Ontario and Manitoba have enabled acquisition adapters. Full source-layer enumeration does not imply complete provincial coverage. Québec and Newfoundland sources require redistribution permission. Other gaps are documented in WELL-SOURCES.md and data/national-coverage.json.

Daily GitHub Actions acquisition is configured for 10:17 UTC. The first manual hosted run succeeded and reproduced all 316,717 records; see VERIFICATION.md and HOSTED-VERIFICATION.json. Twelve transport monitors established baselines; Trans Mountain returned HTTP 403 and remains an explicit failed source check. A candidate artifact is separate from the live release. No public site has been deployed. Deployment remains a manual, gated operation. Transport publications have a change monitor, but rate changes require review and cannot silently become authoritative quotes.

## External requirements

Obtain written permission for the intended Québec and Newfoundland datasets or a genuinely open alternative. Obtain complete historical and offshore inventories where current sources are partial. Reconcile ownership, orphan designation and closure definitions with each authority. Obtain current pipeline and facility coverage with public distribution rights. Determine the supported freight services and commodities before claiming complete carrier or government charges. Confidential contract prices cannot be reconstructed from public schedules.

The public resource must remain noncommercial while using AER data under the verified noncommercial terms. The app includes attribution and does not imply regulator endorsement.

## Verification limits

Source research and automated tests are not a legal certification or a complete security audit. Browser verification covers the candidate's supported flows. Public load, screen-reader speech, actual scheduled recurrence and hosted deployment are separate checks. Results are recorded as performed, rather than inferred from configuration.
