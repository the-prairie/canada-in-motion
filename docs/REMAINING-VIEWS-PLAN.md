# Focus the remaining economy views

The application keeps one normalized economy selection in the shared URL. Income reads current-dollar GDP and later real-growth observations. Futures reads a region, series, scenario and year. Oil has two distinct jobs: a published national price sensitivity and observed provincial historical paths. None of these is a household bill forecast.

## Reading paths and implementation

- Income: selected-place contribution and recent growth, then province comparison. Monthly production follows in a compact strip. Remove repeated row descriptions, next-topic promotions and inline source disclosures. One Evidence action owns definitions, exact monthly history, source links and downloads.
- Futures: one indicator selection, scenario and year control above one chart or electricity-price comparison. Delete the duplicated result headline and repeated assumptions. Keep the observed/projected boundary and scenario interpretation visible. Move exact series values and detailed assumptions to Evidence. Monthly observations remain compact and distinct.
- Oil: explicit Price experiment and Historical record alternatives. The national experiment uses one paired GDP comparison across two years. Historical record owns its episode/province selection and responsive chart. Each alternative has one relevant evidence destination. The history implementation agent owns only its React component and scoped CSS.

Keep the existing SVG and HTML renderers. No new visualization dependency or model changes. Direct labels, existing neutral context and brown/green comparison accents carry the values. Native controls, dialogs and alternate data tables support keyboard use and narrow screens. Oil's new view selection is URL-backed; evidence dialog state is transient. Existing AI/provider configuration remains untouched.

## Alternatives considered

A guided multi-step sequence would hide the comparison while adding another navigation level. Keeping every report section collapsed repeats the previous clutter problem. Focused alternative representations reuse the existing selection and require fewer controls. The independent reviewer will test that this remains understandable on desktop and mobile.
